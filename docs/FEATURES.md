# شرح پروژه و ویژگی‌ها — استودیو بوم بی‌نهایت

> **Infinite Canvas Studio** نسخهٔ ۱٫۴۸٫۳ — بوم بی‌نهایتِ **کاملاً آفلاین** با پشتیبانی درجه‌یک از **فارسی و راست‌به‌چپ (RTL)**.
> اجرا به‌صورت وب (Next.js) و دسکتاپ ویندوز (Tauri 2) — **یک کد مشترک**، دو پوسته.

## پروژه در یک نگاه

| ویژگی کلیدی | توضیح |
|---|---|
| بوم بی‌نهایت | فضای کاری بدون مرز با دوربین روان (بزرگ‌نمایی، چرخش دید، نقشهٔ بوم) |
| فارسی‌محور | رابط فارسی RTL، ارقام فارسی، نیم‌فاصله، تاریخ شمسی، شکل‌دهی صحیح متن در همهٔ خروجی‌ها |
| صددرصد آفلاین | هیچ سرور/حسابی لازم نیست؛ حتی تبدیل رسانه با ffmpeg.wasm داخل برنامه انجام می‌شود |
| فرمت پروژهٔ اختصاصی `.icb` | ذخیرهٔ نسخه‌دار با مهاجرت‌های خودکار (v1→v6) و پوشهٔ رسانهٔ sidecar |
| پنج خروجی | PNG · SVG · PDF (چاپ) · Word (docx با جدول واقعی) · Markdown |
| معماری افزونه‌پذیر | رجیستری‌های فرمان/شیء/پنل/تنظیمات + اجراپیمای افزونه با سندباکس و مجوز |
| لایهٔ دانش | پیوند ویکی، برچسب، ویژگی ساخت‌یافته، کوئری زنده، گراف دانش |
| ۲٬۴۴۴ تست خودکار | ۲۱۸ فایل تست — همه سبز (وضعیت انتشار این نسخه) |

### ۵. رسانه (فازهای M1/M2 ویدئو، A1/A2 صوت، P1/P2 سند PDF)
- ✅ درج تصویر PNG/JPG/WebP (چندتایی؛ کشیدن‌ورها، Ctrl+V، دیالوگ) — تصویر داخل فایل پروژه embed می‌شود
- ✅ درج ویدئو MP4/WebM/MOV/OGV با پوستر بندانگشتی + **پنجرهٔ پخش شناور** (پخش، ۱۰± ثانیه، صدا، سرعت، تمام‌صفحه)

- ✅ **تبدیل آفلاین** قالب‌های ناسازگار به MP4/MP3 با ffmpeg.wasm — فایل اصلی حفظ می‌شود، قابل لغو
- ✅ ورق‌زدن PDF روی خود بوم (چرخ موس روی بندانگشتی) با ذخیرهٔ صفحه در فایل و کش پوستر
- ✅ ذخیرهٔ رسانه‌ها با hash در پوشهٔ sidecar — کپی/انتقال پروژه لینک‌ها را نمی‌شکند؛ **در نسخهٔ دسکتاپ از پروتکل داخلی `icbasset://` با پشتیبانی Range استریم می‌خواند** (فاز D1)
