# راهنمای کاربر — استودیو بوم بی‌نهایت (Infinite Canvas Studio)

نسخهٔ ۱٫۴۸٫۳ — این راهنما **تمام کارها و قابلیت‌های رابط کاربری** را قدم‌به‌قدم توضیح می‌دهد.
از فهرست بالا هر بخشی را که لازم داشتید بخوانید؛ بخش «شروع در ۵ دقیقه» برای اولین استفاده کافی است.

> برنامه کاملاً **آفلاین** است: هیچ سرور، حساب کاربری یا اینتری لازم ندارد.
> زبان پیش‌فرض فارسی و راست‌به‌چپ (RTL) است و همهٔ اعداد رابط با **ارقام فارسی** نمایش داده می‌شوند.

## ۱) شروع در ۵ دقیقه

### اجرای نسخهٔ وب (ساده‌ترین راه)

```bash
npm install     # فقط بار اول (چند دقیقه)
npm run dev     # اجرای برنامه
```

سپس در مرورگر آدرس **http://localhost:3000** را باز کنید. همین!

### اجرای نسخهٔ دسکتاپ ویندوز (exe)

پیش‌نیازها: **Node.js 18+**، **Rust** (از rustup.rs) و **Visual Studio Build Tools** با بستهٔ C++.

```bash
npm install
npm run tauri:build
```

- نصب‌کنندهٔ رسمی: `src-tauri\target\release\bundle\nsis\Infinite Canvas Studio_1.48.5_x64-setup.exe`
- exe مستقیم (بدون نصب): `src-tauri\target\release\infinite-canvas-studio.exe`

> بار اولِ کامپایل Rust بین ۵ تا ۲۰ دقیقه طول می‌کشد؛ کاملاً طبیعی است.
> در نسخهٔ دسکتاپ، دابل‌کلیک روی فایل `.icb` در ویندوز مستقیماً برنامه را با همان پروژه باز می‌کند (یکپارچگی ویندوز).

### اولین کارها روی بوم

1. کلید **N** را بزنید (ابزار یادداشت) و روی بوم کلیک کنید → یک کارت رنگی ظاهر می‌شود؛ تایپ کنید و با **Esc** تمام کنید.
2. کلید **S** را بزنید (ابزار شکل) و با کشیدن ماوس یک مستطیل بکشید.
3. کلید **V** را بزنید (ابزار انتخاب) و اشیاء را جابه‌جا کنید.
4. **Ctrl+S** بزنید و پروژه را با پسوند `.icb` روی دیسک ذخیره کنید.

## ۲) آشنایی با صفحه

صفحه از این بخش‌ها تشکیل شده است:

| بخش | جای آن | چهکاری می‌کند |
|---|---|---|
| **نوار عنوان سند** | بالای صفحه | نام سند جاری (کلیک = تغییر نام)، وضعیت ذخیره، دکمهٔ «پروژه» (منوی کامل پروژه)، بزرگ‌نمایی، واگرد/بازانجام، جستجو و جایگزینی، چسبندگی به شبکه، تنظیمات، تغییر زبان، تغییر پوسته |
| **جعبه‌ابزار عمودی** | لبهٔ راست | ۱۰ ابزار: انتخاب، جابه‌جایی، قلم، پاک‌کن، متن، یادداشت، جدول، شکل، اتصال، قاب — هر ابزار با کلید تکی خودش فعال می‌شود |
| **پنل درج** | داک چپ | کاتالوگ کارت‌ها: شکل‌ها، متن و یادداشت، استیکرها، رسانه (تصویر/ویدئو/صوت/PDF)، رسم، دانش |
| **پنل‌های کناری** | داک راست | لایه‌ها، بازرس، جستجو، تاریخچهٔ نسخه‌ها، افزونه‌ها، اتوماسیون، گراف دانش، برچسب‌ها |
| **نقشهٔ بوم (Minimap)** | داک پایین | نمای کوچک کل بوم؛ داخلش بکشید تا دید جابه‌جا شود |
| **نوار وضعیت** | پایین صفحه | ابزار فعال، بزرگ‌نمایی، مختصات نشانگر، تعداد اشیاء/انتخاب‌شده‌ها، وضعیت ویرایش متن، وضعیت ذخیرهٔ خودکار، ساعت |
| **بوم بی‌نهایت** | وسط | صفحهٔ اصلی کار — با اسکرول/پینچ بزرگ‌نمایی و با Space+کشیدن یا ابزار دست (H) جابه‌جایی |

نوارهای پنل با کلیک روی عنوانشان باز/بسته می‌شوند و وضعیتشان به‌خاطر سپرده می‌شود.

## ۳) ابزارها و میان‌برها

| ابزار | کلید | کاربرد |
|---|---|---|
| انتخاب | **V** | انتخاب، جابه‌جایی، تغییر اندازه و چرخاندن اشیاء |
| جابه‌جایی (دست) | **H** | حرکت دادن دوربین روی بوم |
| قلم | **P** | رسم آزاد؛ منوی کنار ابزار: حالت **قلم** یا **هایلایتر** و رنگ |
| پاک‌کن | **E** | پاک‌کردن خط‌های قلم |
| متن | **T** | جعبهٔ متن غنی؛ کلیک روی بوم = درج در همان نقطه |
| یادداشت | **N** | کارت رنگی چسبان؛ کلیک = درج، رنگ از منوی کنار ابزار |
| جدول | **G** | جدول با ابعاد دلخواه (مثل ۳×۳)؛ بعد از درج کامل قابل ویرایش |
| شکل | **S** | مستطیل، گردگوشه، بیضی، مثلث، لوزی، ستاره — با کشیدن رسم می‌شود |
| اتصال | **C** | خط اتصال بین دو شیء؛ کلیک روی شیء اول، بعد شیء دوم — یا بکشید |
| قاب | — (از جعبه‌ابزار یا پنل درج) | قاب دور اشیاء برای گروه‌بندی دیداری، ارائه و چینش خودکار |

نکته‌های دوربین:

- **اسکرول** روی بوم = جابه‌جایی دید؛ **Ctrl+اسکرول** = بزرگ‌نمایی.
- **Ctrl+0** بازنشانی بزرگ‌نمایی به ۱۰۰٪، **Ctrl+1** نمایش همهٔ محتوا (Fit).
- **Space را نگه دارید** و بکشید = جابه‌جایی موقت (ابزار قبلی برمی‌گردد).
- **کلیدهای جهت** جابه‌جایی انتخاب (بدون کلید = ۱px، با Shift = پرش بزرگ‌تر).

## ۴) ساخت اشیاء

هر چیزی که روی بوم می‌گذارید یک «شیء» است. راه‌های درج:

1. **جعبه‌ابزار** — ابزار را فعال کنید و روی بوم کلیک/کشیدن کنید.
2. **پنل درج** — روی کارت کلیک کنید (شیء در وسط دید ظاهر می‌شود) یا کارت را **بکشید** و هرجای بوم رها کنید (در همان نقطه درج می‌شود).
3. **کشیدن‌ورها کردن (Drag & Drop)** — فایل تصویر/ویدئو/صوت/PDF را از ویندوز روی بوم بیندازید.
4. **کپی/چسباندن** — از حافظهٔ سیستم متن، HTML یا تصویر بچسبانید (**Ctrl+V**).
5. **منوی راست‌کلیک** — «درج تصویر…» و گزینه‌های دیگر.

انواع شیء: جعبهٔ متن، یادداشت، شکل، خط قلم، جدول، تصویر، ویدئو، صوت، سند PDF، استیکر، قاب، گروه، اتصال، کوئری زندهٔ دانش و اشیاء افزونه.

- **استیکرها**: از پنل درج (۸ استیکر سریع) یا کتابخانهٔ کامل با **Ctrl+Shift+K** — بیش از ۲۰۰ استیکر با جستجوی فارسی/انگلیسی، دسته‌بندی، اندازهٔ درج (کوچک/متوسط/بزرگ)، اخیراً استفاده‌شده‌ها و امکان «درج سنجاق‌شده».
- **سنجاق روی صفحه (Pin)**: هر شیء را می‌توان روی صفحه سنجاق کرد تا با حرکت دوربین تکان نخورد (مثل یادداشت روی تخته). جای سنجاق ۹ نقطهٔ صفحه + اندازهٔ دلخواه + چرخش. از راست‌کلیک → «سنجاق روی صفحه».

## ۵) ویرایشگر متن غنی و جدول‌ها

روی هر جعبهٔ متن یا یادداشت **دابل‌کلیک** کنید تا ویرایشگر باز شود. چه چیزهایی دارید:

### قالب‌بندی نویسه‌ها
درشت (**Ctrl+B**)، مورب (**Ctrl+I**)، زیرخط (**Ctrl+U**)، خط‌خورده، زیرنویس/بالانویس، رنگ متن، هایلایت، قلم (وزیرمتن/تاهوما/سریف/هم‌عرض/سیستم)، اندازهٔ قلم.

### بلوک‌ها
عنوان ۱ تا ۳، متن ساده، نقل‌قول، بلوک کد، خط جداکننده، فهرست نقطه‌ای/شماره‌دار/کارها (چک‌باکس دار).

### جهت و فارسی
تراز راست/وسط/چپ/کامل، جهت بلوک **راست‌به‌چپ یا چپ‌به‌راست**، درج **نیم‌فاصله** (ZWNJ)، درج **تاریخ امروز شمسی** (متنی یا عددی — مثل ۲۱ مرداد ۱۴۰۳)، تبدیل خودکار ارقام تایپی به فارسی (قابل فعال‌سازی در تنظیمات).

### پیوندها
**Ctrl+K** = درج/ویرایش پیوند اینترنتی؛ کلیک روی پیوند با تأیید در مرورگر سیستم باز می‌شود.

### جدول‌ها
با ابزار جدول (G) درج کنید؛ سپس از نوار ابزار جدول: افزودن/حذف سطر و ستون (قبل/بعد)، ادغام و تفکیک سلول‌ها (افقی/عمودی)، سطر/ستون عنوان، **جهت راست‌به‌چپ جدول** (ستون ۱ در راست)، ۶ قالب ظاهری (کلاسیک، مینیمال، راه‌راه، ملایم، شبکه‌ای، تیره)، پس‌زمینهٔ سلول، تراز عمودی و **توزیع یکنواخت عرض ستون‌ها**.

### جستجو و جایگزینی
**Ctrl+F** — داخل متنِ در حال ویرایش: نتیجهٔ بعدی/قبلی، جایگزینی تکی یا همه، شمارندهٔ «۳ از ۱۲».

### قلم‌نگار (Format Painter)
**Ctrl+Alt+C** قالب‌بندی یک متن را کپی می‌کند و **Ctrl+Alt+V** روی متن دیگر اعمال می‌کند.

## ۶) انتخاب، جابه‌جایی و چیدمان

- **کلیک** = انتخاب یک شیء؛ **کشیدن از فضای خالی** = انتخاب چندتایی (Marquee)؛ **Ctrl+کلیک** = افزودن به انتخاب؛ **Ctrl+A** = انتخاب همه؛ **Esc** = لغو انتخاب.
- **دستگیره‌های گوشه** = تغییر اندازه؛ **دستگیرهٔ گرد بالای شیء** = چرخاندن آزاد (مرکز ثابت می‌ماند).
- **Alt+کشیدن** = تکثیر سریع در همان حرکت.
- **Delete / Backspace** = حذف (هر دو کلید).
- **Ctrl+D** = تکثیر؛ **Ctrl+G / Ctrl+Shift+G** = گروه‌کردن / گروه‌شکنی؛ **Ctrl+L** = قفل/بازکردن قفل (شیء قفل‌شده جابه‌جا نمی‌شود ولی انتخاب می‌شود).
- **ترتیب لایه**: `Ctrl+Shift+]` رو‌به‌رو، `Ctrl+]` یک لایه جلوتر، `Ctrl+[` یک لایه عقب‌تر، `Ctrl+Shift+[` پشت‌همه — هم از منوی راست‌کلیک.
- **چیدمان (Align/Distribute)**: چیدمان به چپ/راست/وسط افقی و بالا/پایین/میانهٔ عمودی + **توزیع افقی/عمودی با فاصلهٔ برابر** — از نوار عملیات انتخاب.
- **چسبندگی و راهنمای هوشمند**: حرکت اشیاء با خطوط راهنمای هم‌ترازی (Smart Guides) و چسبیدن به شبکه (کلید Ctrl+. برای خاموش/روشن کردن موقت).
- **نوار عملیات انتخاب**: دکمه‌های شناور کنار انتخاب — تکثیر، حذف، گروه، قفل، ویرایش متن، ترتیب لایه.
- **بازنشانی تصویر**: برای تصویرها — بازنشانی به اندازهٔ اصلی، بازنشانی نسبت، بازگشت به «حالت لحظهٔ درج» (تصویر در لحظهٔ درج کجا و چه‌اندازه بود) و نمایش انحراف نسبت از اصلی.

## ۷) رسانه: تصویر، ویدئو، صوت و PDF

### درج
- منوی «پروژه» → **درج تصویر…/درج ویدئو…/درج صوت…/درج PDF…** (یا کارت‌های گروه «رسانه» در پنل درج، یا کشیدن فایل روی بوم، یا Ctrl+V).
- در دیالوگ درج می‌توان **چند فایل هم‌زمان** انتخاب کنید.
- قالب‌های پذیرفته‌شده:
  - تصویر: PNG · JPG · WebP
  - ویدئو: MP4 · WebM · MOV · OGV
  - صوت: MP3 · M4A · AAC · OGG · WAV · FLAC
  - سند: PDF (با امضای معتبر)

### تبدیل آفلاین
اگر قالبی پخش مستقیم نمی‌شود (مثلاً ویدئو AVI یا صوت FLAC در برخی حالت‌ها)، دیالوگ **«تبدیل به MP4/MP3 (آفلاین)»** باز می‌شود: کاملاً بدون اینترنت و داخل برنامه تبدیل می‌شود، **فایل اصلی نگه داشته می‌شود** و نسخهٔ تبدیل‌شده کنارش قرار می‌گیرد. می‌توانید حین تبدیل لغو کنید.

### نمایش روی بوم
- **تصویر**: خودِ عکس روی بوم.
- **ویدئو**: تصویر بندانگشتی (پوستر) با دکمهٔ پخش؛ **دابل‌کلیک** = پخش‌کنندهٔ شناور.
- **صوت**: کارت با **موج صدا** (Waveform)؛ **دابل‌کلیک** = پخش‌کنندهٔ صوت شناور.
- **PDF**: بندانگشتی صفحهٔ جاری؛ **دابل‌کلیک** = نمایشگر شناور.

### پنجره‌های شناور (هر سه قابل جابه‌جایی با کشیدن نوار عنوان و تغییر اندازه از گوشه):
- **پخش‌کنندهٔ ویدئو**: پخش/توقف، ۱۰ ثانیه عقب/جلو، نوار زمان، بلندی صدا، بی‌صدا، **سرعت پخش**، تمام‌صفحه، بستن (× یا Esc).
- **پخش‌کنندهٔ صوت**: همان کنترل‌ها (بدون تصویر) با نوار موج صدا.
- **نمایشگر PDF**: صفحه‌قبل/بعد، شمارهٔ صفحه (تایپ عددی)، بزرگ/کوچک‌نمایی، **هم‌عرض پنجره (۰)**، **تمام‌صفحه (F)**؛ چرخش موس = ورق زدن، Ctrl+چرخ = بزرگ‌نمایی سند. **متن سند قابل انتخاب و کپی است** (Ctrl+C) و فارسی درست کپی می‌شود. اسکرول روی بندانگشتی = ورق زدن صفحه (صفحهٔ جدید روی بوم ذخیره می‌شود).

> روی هر بندانگشتی، کلیک = انتخاب، دابل‌کلیک = باز کردن پنجرهٔ شناور. ورق‌زدن روی بوم (بدون نمایشگر) هم کار می‌کند.

## ۸) دانش و پیوند بین اشیاء

این برنامه یک لایهٔ «دانش» دارد — مثل یک ویکی داخل بوم:

- **پیوند ویکی**: داخل متن هر شیء بنویسید `[[عنوان شیء دیگر]]` — حین تایپ، پیشنهاد خودکار عنوان‌ها می‌آید و می‌توانید «ایجاد و پیوند» بزنید.
- **برچسب**: داخل متن `#برچسب` بگذارید.
- **ویژگی‌های ساخت‌یافته**: به هر شیء ویژگی اضافه کنید — متن، عدد، تاریخ، بله/خیر، انتخاب (لیست کشویی) یا برچسب‌ها. مثلاً «مسئول: علی» یا «وضعیت: در‌حال‌انجام».
- **پیوند دستی**: راست‌کلیک روی شیء → **«لینک به این شیء…»** — مقصد را از فهرست (با جستجو) انتخاب کنید؛ پیوندهای معلق/گمشده هم نشان داده می‌شوند.
- **کوئری زندهٔ دانش**: کارتی روی بوم که به‌صورت زنده نتیجهٔ یک پرس‌وجو را نشان می‌دهد: پیوندهای ورودی یک عنوان، اشیاء یک برچسب، پیوندهای گمشده، جزیره‌ها (اشیاء بدون پیوند) یا **فیلتر ساخت‌یافتهٔ کامل** (ویژگی‌ها با عملگرهای = ≠ > < شامل/شروع‌با + مرتب‌سازی + گروه‌بندی + سقف نتایج). با هر تغییری زنده به‌روز می‌شود.
- **پنل گراف دانش**: نمای گرافیکی عنوان‌ها و پیوندها (اندازهٔ گره = تعداد پیوند، خط‌چین قرمز = پیوند گمشده) + آمار. کلیک روی گره = پرش به شیء؛ دکمهٔ **«چینش روی بوم»** کل گراف را با الگوریتم نیرومحور مرتب می‌کند (یک مرحلهٔ واگرد دارد).
- **نمایش/پنهان‌کردن پیوندهای دانش روی بوم**: خط‌های اتصال دانشی روی خود بوم.
- **پنل برچسب‌ها**: فهرست زندهٔ همهٔ برچسب‌ها؛ کلیک = فیلتر نتایج جستجو با آن برچسب.
- **پیوند عمیق (Deep Link)**: راست‌کلیک → «کپی پیوند عمیق شیء» — لینکی که همان شیء را در همان پروژه باز می‌کند (در نسخهٔ دسکتاپ دابل‌کلیک روی آن برنامه را با پروژه و شیء باز می‌کند).

## ۱۰) ذخیره، بازیابی و نسخه‌ها

### ذخیرهٔ خودکار
- هر **۳۰ ثانیه** (قابل تنظیم) اگر تغییر ذخیره‌نشده باشد، به‌صورت خودکار ذخیره می‌شود؛ هنگام بستن/مخفی‌کردن تب هم فوراً.
- در نسخهٔ وب: در حافظهٔ مرورگر؛ در دسکتاپ: در `C:\Users\<کاربر>\AppData\Roaming\app.infinitecanvas.studio\autosave.icb`.
- **بازیابی**: اگر برنامه ناخواسته بسته شود، موقع اجرای بعدی دیالوگ «بازیابی آخرین تغییرات؟» ظاهر می‌شود.

### ذخیره و فراخوانی روی دیسک
- **Ctrl+S** «ذخیره» / **Ctrl+Shift+S** «ذخیره در مسیر…» / فراخوانی از مسیر یا **Ctrl+O**.
- در ویندوز **پنجرهٔ ذخیره/بازکردن خود سیستم** باز می‌شود (انتخاب پوشه و نام فایل). مسیر تایپی دستی هم مجاز است.
- فرمت اختصاصی **`.icb`** — همه‌چیز (صحنه، دوربین، رسانه‌ها در پوشهٔ کناری `<فایل>.icb.assets/`، بخش افزونه‌ها) داخلش است.
- **فایل‌های اخیر**: فهرست پروژه‌های اخیر با پرش سریع؛ فایل پاک‌شده هم تشخیص داده می‌شود.
- **محافظ خروج**: اگر تغییرات ذخیره‌نشده باشد، پیش از «پروژهٔ جدید»/بستن، دیالوگ «ذخیره / بدون ذخیره / انصراف» می‌آید.

### نسخه‌ها
پنل «تاریخچه» → هر ذخیرهٔ دستی یک snapshot زمان‌دار؛ پیش‌نمایش، بازگردانی، حذف.

### تبادل Markdown
- **خروجی Markdown**: هر شیءٔ متنی یک فایل `.md` (عنوان + شناسنامه + متن غنی) + `index.md` — به‌صورت ZIP.
- **درون‌ریزی Markdown**: فایل‌های `.md` را انتخاب کنید؛ هر فایل یک کارت متنی می‌شود (تیتر = عنوان، frontmatter = شناسنامهٔ شیء).
- **پوشهٔ آینهٔ Markdown** (تنظیمات → ذخیره‌سازی): بعد از هر ذخیره، خروجی Markdown در `<پروژه>.icb.md/` نوشته می‌شود (یک‌طرفه؛ فایل icb مرجع است).

## ۱۱) خروجی گرفتن (PNG/SVG/PDF/Word/Markdown)

از منوی «پروژه»:

| خروجی | نکات |
|---|---|
| **PNG** | محدوده: کل بوم یا فقط انتخاب؛ مقیاس دلخواه؛ پس‌زمینه رنگ بوم یا شفاف؛ پیش‌نمایش اندازهٔ دقیق |
| **SVG** | برداری؛ متن‌ها به‌صورت تصویر جاسازی می‌شوند تا شکل‌دهی فارسی دقیق بماند |
| **PDF** | پنجرهٔ چاپ باز می‌شود (گزینهٔ «ذخیره به‌صورت PDF»)؛ چینش: **یک قاب در هر صفحه** یا **همهٔ محتوا در یک صفحه** |
| **Word** | فایل `.docx` با ساختار کامل — سرتیترها، بولد/مورب، فهرست‌ها و **جدول‌های واقعی (با سربرگ، ادغام‌ها و راست‌به‌چپ)** |
| **Markdown** | بخش ۱۰ را ببینید |
| **کپی به‌صورت تصویر** | (منوی راست‌کلیک یا Ctrl+Alt+Shift+C) تصویر PNG انتخاب در حافظهٔ سیستم |
| **کپی متن غنی** | متن قالب‌بندی‌شده HTML در حافظه — در Word و چت‌های هوش مصنوعی با همان ساختار می‌چسبد |

در همهٔ خروجی‌های تصویری می‌توانید **اشیای سنجاق‌شده را هم شامل کنید** (با همان جای نسبی روی صفحه؛ در PDF روی هر صفحه تکرار می‌شوند).

## ۱۲) حالت ارائه (F5) و قالب‌ها

- **F5** = شروع ارائه روی قاب‌ها؛ هر قاب یک اسلاید. حرکت با **→ ← یا Space**، خروج با **Esc**. شمارهٔ اسلاید و نوار پیشرفت نمایش داده می‌شود. (حداقل یک قاب لازم است.)
- **گالری قالب‌ها**: «پروژهٔ جدید» (Ctrl+N) → شروع با قالب آماده (مثل کانبان) یا بوم خالی.
- **چینش خودکار قاب**: قاب را انتخاب کنید و در بازرس «چینش خودکار (ردیف/ستون)» را فعال کنید — فرزندان قاب خودکار ردیف/ستون می‌شوند؛ جابه‌جایی یک فرزند یعنی تغییر ترتیب. (از API افزونه هم قابل استفاده است.)

## ۱۳) افزونه‌ها و اتوماسیون

### افزونه‌ها
- پنل «افزونه‌ها» → ⬆ → نصب از **فایل ZIP**، از **پوشه** (نسخهٔ دسکتاپ) یا **افزونهٔ نمونه** (Sticky Shape Pack).
- **فروشگاه افزونه‌ها**: افزونه‌های داخلی رسمی — 🗓 تقویم، ✅ برنامه‌ریز، 📊 گزارش‌گر، 🤖 تحلیلگر هوش، 📝 یادداشت روزانه — همه آفلاین. جستجو، دسته‌بندی، فعال/غیرفعال، حذف.
- موقع نصب، **مجوزهای** درخواستی به فارسی فهرست می‌شود و رضایت شما شرط است.
- افزونه می‌تواند: کارت در پنل درج، فرمان، پنل، بخش تنظیمات و دادهٔ خودش را اضافه کند. حذف با آرشیو = بازگردانی بعدی ممکن است.

### اتوماسیون
پنل «اتوماسیون» → «ساخت قانون جدید»:
- **وقتی**: هر تغییری / ذخیرهٔ پروژه / اجرای برنامه / تغییر دادگان برنامه‌ریز، تقویم، خلاصهٔ پروژه، کوئری صحنه، یادداشت روزانه / تغییر پیوند دانشی / تغییر وضعیت افزونه‌ها.
- **آنگاه**: اجرای یک فرمان دلخواه (از پالت فرمان‌ها) یا نوشتن در مرکز داده (قراردادهای افزونه‌های داخلی).
- هر اجرا در «گزارش اجرا» ثبت می‌شود.

## ۱۶) پرسش‌های رایج

**کارم ذخیره نشده بود و برنامه بسته شد — از کجا برمی‌گردد؟**
موقع اجرای بعدی، دیالوگ «بازیابی آخرین تغییرات؟» خودش ظاهر می‌شود؛ «بازیابی» را بزنید.

**فایل‌های رسانهٔ درج‌شده کجا ذخیره می‌شوند؟**
داخل همان پروژه: به‌صورت sidecar کنار فایل `.icb` در پوشهٔ `<فایل>.icb.assets/`. قبل از اولین «ذخیره در مسیر…» در محل موقت سیستم (`media-inbox`) می‌مانند و بعد خودکار منتقل می‌شوند — بدون خراب‌شدن لینک‌ها.

**چرا متن SVG تصویر شد؟**
برای حفظ شکل‌دهی دقیق حروف فارسی؛ برای متن قابل انتخاب از خروجی PDF یا کپی متنی استفاده کنید.

**دابل‌کلیک روی فایل .icb در ویندوز برنامه را باز نکرد.**
یک بار برنامه را از نصب‌کننده نصب کنید تا یکپارچگی فایل ثبت شود؛ بعد دابل‌کلیک مستقیم کار می‌کند (یا از داخل برنامه: Ctrl+O).

**برای exe، چه پیش‌نیازی لازم است؟**
Node.js + Rust + Visual Studio Build Tools (C++). اگر ارور `link.exe not found` گرفتید، بستهٔ C++ نصب نیست.

**می‌خواهم همهٔ چیز را یکجا ببینم.**
Ctrl+1 (نمایش همهٔ محتوا) یا پنل «نقشهٔ بوم».

**پروژه را چطور با دیگران به اشتراک بگذارم؟**
فایل `.icb` **و** پوشهٔ `<فایل>.icb.assets/` را با هم بفرستید (یا خروجی PNG/PDF/Word بگیرید). دانلود تک‌فایلی هم از منوی پروژه ممکن است.
